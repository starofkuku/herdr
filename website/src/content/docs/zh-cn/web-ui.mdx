---

`herdr web` 将 Herdr 的终端 UI 提供给浏览器，并把浏览器的输入桥接回你的会话。它作为独立进程运行，不隶属于任何会话服务器，因此可以列出所有会话并让你选择。

这适用于通过 WireGuard 或 SSH 隧道等私有网络访问你自己的机器。它不是托管服务。

## 为什么是独立进程

每个 Herdr 会话都有自己的服务器，而会话服务器只知道自己那一个会话。只有位于它们之外的进程才能枚举全部会话并提供选择。`herdr web` 就是那个进程：一个监听器、一个端口、所有会话。

浏览器只是另一个客户端。它和终端以相同方式连接，因此浏览器和终端可以同时查看同一个会话并共享同一份状态。

## 启用网关

除非配置了密钥，否则网关处于禁用状态。这是有意为之：开放的网关等同于远程 shell 访问，因此它绝不会在没有认证的情况下监听。

把密钥放进 `config.toml`，这样重启后依然有效：

```bash
key=$(head -c 32 /dev/urandom | base64)
```

```toml
[web]
key = "你生成的密钥"
```

```bash
chmod 600 ~/.config/herdr/config.toml
herdr web
```

没有密钥时，它会打印诊断信息并退出，而不是绑定端口。

密钥至少需要 16 个字符。它使用常量时间比较，并且永远不会写入日志。

由于 `config.toml` 中的密钥只和该文件一样私密，当文件可被其他用户读取时 Herdr 会拒绝启动，并提示执行 `chmod 600`。临时运行请改用 `HERDR_WEB_KEY`。

密钥至少需要 16 个字符。它使用常量时间比较，并且永远不会写入日志。

## 配置

```toml
[web]
# Address to listen on. Default: 127.0.0.1
bind = "127.0.0.1"
# TCP port. Default: 8787
port = 8787
# Directory containing the built web UI. Optional.
static_dir = "/home/you/herdr/web/dist"
# Optional Origin allowlist. Empty disables the check.
allowed_origins = []
# Gateway key. Keep this file at chmod 600.
key = "..."
```

建议绑定私有接口而不是 `0.0.0.0`，这样端口只能从你预期的网络访问。

密钥来源按以下顺序读取：

密钥来源按优先级顺序：

- `HERDR_WEB_KEY`
- `HERDR_WEB_KEY_FILE`，一个包含密钥的文件
- `config.toml` 中的 `[web] key`

基于文件的密钥不得被其他用户读取，Herdr 对 `config.toml` 和 `HERDR_WEB_KEY_FILE` 都会强制这一点。

不要把密钥放进 `config.toml`。该文件通常对同机其他用户可读，而 Herdr 自己的 socket 仅限所有者访问。

## 提供 UI

网关在请求时从 `static_dir` 读取 UI；它永远不会被嵌入 herdr 二进制，因此你可以独立更新或替换它。未设置 `static_dir` 时，只提供 WebSocket 端点。

构建内置 UI：

```bash
cd web && bun install && bun run build
```

这会生成单个自包含的 `web/dist/index.html`。把 `static_dir` 指向该 `dist` 目录。

每个版本也会把同一个文件作为 `herdr-web-ui.html` 资产发布,因此你可以直接使用已发布的 UI,无需自行构建。下载到一个目录,并把 `static_dir` 指向该目录。

由于网关自己提供页面，页面与 WebSocket 同源，因此不需要额外的托管或 CORS 配置。

## 连接

在浏览器中打开网关地址，输入密钥，然后选择会话或输入新名称。

- 打开未运行的会话会启动它的服务器。
- 会话名可使用字母、数字、`.`、`_` 和 `-`。
- 多个客户端可以连接同一个会话并共享状态。
- 终端会随浏览器视口调整大小，因此窄屏手机自动使用 Herdr 的移动端布局。

如果你保存了密钥,UI 还会记住你最后打开的会话,刷新页面后会直接回到该会话。用返回按钮主动离开会话会清除这一记忆,因此刷新后仍停留在选择页。

鼠标输入也可用：可以直接点击标签页、窗格和菜单。由于 TUI 会捕获鼠标,拖拽选择会交给应用处理;如需在本地选择和复制文本,请按住 **Shift** 拖拽。macOS 上请按住 **Option**。

通知不会投递到浏览器。Agent 状态、终端输出和输入会。

## 远程访问

WireGuard 和 SSH 隧道是预期的访问方式。传输使用明文 `ws://`，因为隧道本身已经提供加密。

绑定到你的私有地址：

```toml
[web]
bind = "10.0.0.5"
```

或者保留默认的环回绑定，并通过 SSH 转发端口：

```bash
ssh -L 8787:127.0.0.1:8787 you@server
```

转发后的端口可通过 `ws://127.0.0.1:8787` 访问。不要把网关直接暴露到公网：密钥只是一个保护 shell 访问的静态秘密，不能替代隧道。

如果你把页面托管在网关之外的位置，请设置 `allowed_origins`，以免其他站点从浏览器连接你的网关。注意部分浏览器还会限制公网 HTTPS 页面访问私有网络地址。

## 分离

使用返回按钮离开会话；会话及其窗格会继续运行。关闭浏览器标签页会干净地分离，不会停止服务器。

要停止会话及其窗格，请使用 `herdr session stop <name>`。
